# ai-lab

Лаборатория: эксперименты с LLM, первые автоматизации, заметки.

## Структура

```
ai-lab/
├── 00_setup/        # проверка окружения
├── 01_basics/       # токены, температура, первые вызовы API
├── 02_prompts/      # промпт-контракты, structured output
├── 03_rag/          # поиск по документам
├── 04_agents/       # агенты и инструменты
├── experiments/     # быстрые проверки гипотез (можно ломать)
├── notes/           # конспекты, разборы, «что не сработало»
├── .env             # КЛЮЧИ (в git не попадает)
└── .env.example     # шаблон без секретов
```

## Быстрый старт

```powershell
cd ai-lab
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# вписать ключи в .env
python 00_setup/check_env.py
```

## Правила

1. Ключи только в `.env`. Никогда в код, в git, в чат.
2. Каждый эксперимент — отдельный файл с датой в имени.
3. В `notes/` пишем не «что сделал», а «что понял» и «что не сработало».
4. Ни одна строка кода не принимается, пока не могу её объяснить.
